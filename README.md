# Spotify UI Clone

## Overview

Spotify UI Clone is a responsive front-end project built using **HTML5** and **CSS3**.The project includes the sidebar you see on Spotify, the section for played music, cards for albums and the controls for playing music. I focused on making it look good and feel right which is important for UI and UX.

## Features

- Spotify-inspired dark theme
- Responsive layout for desktop, tablet, and mobile devices
- Interactive album cards with hover effects
- Music player controls including play, pause, previous, next, and volume slider
- Sidebar navigation for Home, Search, and Library
- Clean and modern user interface

## Tech Stack

- **HTML5** – Structured the content and layout of the application.
- **CSS3** – Styled the interface, created responsive layouts, and added hover effects and animations.

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/arelli-sanjay/Spotify-UI-Clone.git
```

2. Open the project folder. 

3. Open `index.html` in your web browser.
